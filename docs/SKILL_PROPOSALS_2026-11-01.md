## Tier 1: new skills, with recurrence across repositories or money at stake

### 1. `prove-it-can-pass`: a deny-level gate is proved on innocent input as well as on the violation

**Evidence (6 instances, 3 repositories):** library 25 (the secret guard refused a test tally named `pass`), the 2026-09-16 overnight stall recorded in `hooks/preflight-unattended.mjs:5-10` (push-gate matched "gh pr merge" inside a commit message and held a run for fourteen hours; its suite was 64 invented commands), ICC L-126 (a caption guard built from the customer's name refused "a white carpet" for Mr White, and the retry could not recover without sending the name to the model), PropOS 2026-08-11 (`\bbrowser\.` matched a comment's full stop and killed the whole smoke-db run); the missed-violation direction, where the gate passes the form nobody pictured: library 12 (`git -C x push` walked past push-gate while parallel-work-recon mandates `git -C`), PropOS 2026-08-18 (the guard over `DB_ONLY_SPECS` inspected only listed specs, so an omission exited 0). **Coverage today:** prove-it-can-fail asks what a check prints when the thing is broken, and its rule 3 (`prove-it-can-fail/SKILL.md:30`) is a positive control for negative test assertions. No `SKILL.md` mentions a false positive. preflight-unattended does the real-corpus check for push-gate alone.
**Proposal:** before arming a deny-list, pattern gate or scanner, run it over a real corpus of innocent input (session transcripts for a shell gate, the domain's own vocabulary for a name list: White, Rose, Hall, Wool) and over the forms the library itself mandates; a refusal must be recoverable without disclosing what it refused; a guard over a curated list checks the list's omissions as well as its members.

### 2. `enumerate-the-set`: a change, reset or proof over some members of a set lists the whole set from its source and decides each member

**Evidence (8 instances, 2 repositories):** Rimagent 2026-10-04 (an episode reset named four fields and kept the event cursor), 2026-10-12 (a handover step consumed the pending wait request; only the normal step kind was tested), 2026-10-13 twice (a fight start widened with no matching end; a visibility rule listed the statuses it showed and missed `between_steps`), 2026-10-16 (mod-settings tuning outlived its colony); PropOS 2026-09-21 (two anchors each closed honestly and the general-ledger leg was never written, client money absent from every accounting report), 2026-09-21 (two sound constraints whose permitted transitions do not intersect, so the documented reversal cannot be made), 2026-09-28 (a relay supervisor proven on its clean exit only). **Coverage today:** blast-radius-grep owns the whole set of places a fact lives; unordered-events walks every (event, state) pair for external events and excludes in-process calls; nothing covers fields, step kinds, exit paths or a set of anchors.
**Proposal:** name the set (a state file's fields, the step kinds, the statuses a writer can produce, the exit paths of a supervisor, the anchors over a feature, the transitions two controls permit), list it from the code or the catalog rather than from the change, and decide each member in the code and in a test; a start condition names its end; a reviewer is asked "which member is not covered", not "is this right". Library 44 (one alternative of a pattern proved for all) is the same shape inside a test, and is a prove-it-can-fail row below.

### 3. `spawn-from-declared-state`: a child agent or process starts from configuration, environment and lifetime its launcher declares

**Evidence (5 instances, 1 repository, privacy at stake):** Rimagent 2026-09-26 (a headless `claude -p` ran Ben's SessionStart hook and loaded 131 skills), 2026-10-02 (the same step loaded Ben's CLAUDE.md and auto-memory into an agent narrating to a stream overlay), 2026-10-14 (a show started from a desktop session would inherit the app's `ANTHROPIC_*` and `CLAUDE_CODE_*` variables and an OAuth token), 2026-10-15 (a desktop-app update killed OBS and the overlay because a session had started them), 2026-10-04 (the inverse: 95 orphaned watch loops outlived the monitors that started them and kept an operator heartbeat alive). **Coverage today:** commission-the-roster's least-privilege line (`commission-the-roster/SKILL.md:311`, AI domain L-091) covers connectors on an API-created routine; measure-per-route rule 7 checks that a stop took. Nothing covers what a spawned child inherits. All five are one repository; it is in Tier 1 because the 2026-10-02 instance put the operator's private instructions in front of an audience, and every Claude session on this machine launches children the same way.
**Proposal:** a headless agent is launched with an explicit settings source, tool list, slash-command switch and both `CLAUDE_CODE_DISABLE_AUTO_MEMORY` and `CLAUDE_CODE_DISABLE_CLAUDE_MDS`, and its first run checks the init event's `memory_paths` before any output can reach a reader; a child's environment is an allowlist, not the launcher's minus two names; anything that must outlive the session is started by the OS (a scheduled task), and anything that must not ties itself to its parent's life.

### 4. `instrument-reports-itself`: a measurement or unattended path can say it is broken, and the saying reaches a person in time

**Evidence (7 instances, 4 repositories):** library 11 (the fire log wrote the sentinel `'unknown'` for a month), 13 (a success-only counter cannot see refused demand); Rimagent 2026-10-26 (46 steps that failed authentication were booked at $0.00 and read as a pricing bug while a colonist starved on stream), 2026-10-22 (an unattended ride ran its clock on a paused game and reported the wait as progress); ICC L-128 (three scheduled posts failed terminally and the failure sat in its own row for three days), L-129 (the only check ran weekly, the day before the first failure); PropOS 2026-07-31 (a cancelled required check posts no conclusion, so a merge waits forever and looks slow). **Coverage today:** prove-it-can-fail rule 10 (assert the subject ran) and honest-failure-surfacing (wording and levels); the only "alert" line in any `SKILL.md` is guard-the-spend-paths:32, about guardrails. The 10-22 sweep's preflight-unattended row proves a notification channel before a run, not that failures use it.
**Proposal:** an instrument's failure is a value distinct from every reading (no sentinel, a refusal recorded as a refusal, a step that did no work summed as failed rather than as zero); every terminal failure on an unattended path tells a person once, on the failure's own path, recorded only after the message went; a check runs at least as often as the thing it watches can fail; "no conclusion after N minutes" is its own alarm.
