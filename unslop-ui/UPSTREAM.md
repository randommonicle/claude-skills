## Local patches (not in upstream)

`scripts/devibe_scan.py`:

1. **UTF-8 stdout.** Added `sys.stdout.reconfigure(encoding="utf-8")` after the imports. Without it the scanner crashes with `UnicodeEncodeError` whenever a finding's snippet contains an emoji, on Windows cp1252 consoles.
2. **Broadened the emoji rule.** Replaced the hand-picked ~14-emoji list with full Unicode ranges (the `EMOJI` constant), so the `emoji-as-icons` rule detects any emoji, not just the handful that were hardcoded. (The text/code scanners already did this upstream.)

`references/picking-a-reference.md`, `references/design-reference-index.md`,
`scripts/build_reference_index.py` (all three files are local additions), plus two
sentences in `SKILL.md`:

3. **Design-reference fallback (added 2026-08-06).** Wires in
   https://github.com/scroobius-pip/fudge-design-md (MIT, 287 captured-site DESIGN.md
   guides) as the path when the user cannot name a real reference: a committed
   one-line-per-site index (regenerated by the script), and a method file covering how
   to pick one guide, stay inside its scope note, and take direction rather than brand
   identity. SKILL.md routes to it from the Mode 1 reference bullet and the references
   pointer block; upstream has none of this.

When updating from upstream, keep the three added files and re-apply the SKILL.md
sentences as well as both scanner patches above.
